# DoomRPGEngineToolKit
Fan Tool Kit for Doom RPG Engine Games (Doom RPG, Orcs &amp; Elves, Wolfenstein RPG)

**INSTALLATION GUIDE:**
1. Build itself, of use Release Build
2. In first run, you get Window, where you can pick your LEGALLY OWNED jar, nds, ipa files of those games
3. Have fun and do mods!
